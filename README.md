# 🎮 Replayline  
Repositorio esencial de recursos de videojuegos (clips de gameplay, frases, intros y outros...) diseñado para la comunidad de creadores de contenido. El objetivo es eliminar las horas de búsqueda para que puedas enfocarte en la edición.

🔗 **Demo online:** https://miguelmiguelmiguelmiguelmiguel.github.io/replayline/

---

## 🧩 ¿Qué es Replayline?
Replayline es una pequeña web que permite consultar líneas de diálogo, citas o frases memorables de videojuegos. La idea es tener un sistema ligero, accesible y sencillo para navegar por escenas o frases sin depender de vídeos largos o buscadores caóticos. Se busca que inviertas tu tiempo creando contenido, no buscando clips o fragmentos para tus videos

---

## 🎯 ¿Para qué sirve?
- Para **buscar frases concretas** de videojuegos sin tragarte una cinemática entera.  
- Para tener un **catálogo limpio y ordenado** de diálogos memorables.  
- Para inspirarte, crear contenido o simplemente recordar momentazos.

## 🚀 Roadmap

La idea es ir mejorando la pagina hasta que sea cómoda y útil para usar, la mayor prioridad será añadir clips en el .json para aumentar la cantidad de recursos, pero estos serán los puntos a mejorar:

- Actualizar más la página de recursos individual (poner videos relacionados, actualizar líneas de tiempo, añadir el mismo clip en otros idiomas...).
- Buscador avanzado por juego, frase o palabra clave.  
- Añadir botón de recurso aleatorio.
- Paginación y filtros.  
- Diseño responsive mejorado.  
- Sistema de categorías y etiquetas.
